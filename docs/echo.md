# echo

Writes to stdout.

## Help

```
echo - Writes to stdout.

Options:
  --help, -h
    Displays this help text.

  --version, -v
    Displays version of program.

  --no-new-line, -n
    Removes trailing new line character.

  --escape, -e
    Escapes escape sequences.

  --indent, -i = <number: int> | 4
    Indents output by a number of spaces.
```
